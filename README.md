# k1ng0p Revenge Plugins

Revenge Next plugin repository.

## Install

In Revenge: **Settings → General → Plugins → Add repository**, then paste:

```
https://k1ng0p.github.io/revenge-next-plugins/
```

## Plugins

| Plugin | Description | Ported from |
|---|---|---|
| **Platform Indicators** | Adds platform indicators (Desktop, Mobile, Web) next to usernames in DMs, member list, and profiles. | Original Vendetta plugin by [Martinz64](https://github.com/Martinz64) |
